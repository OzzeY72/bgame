# Стиль-библия

Ориентиры: Stardew Valley (тайлы, здания, вид 3/4 сверху, тёплая палитра) + Undertale
(панель диалога, портреты, монохромный UI). Всё — «честный» пиксель-арт: чёткие пиксели,
без сглаживания, без градиентов, ограниченная палитра.

## Размеры (источник истины: `src/config.ts` ↔ `pipeline/config.yaml`)

| Что | Размер | Примечание |
|---|---|---|
| Внутреннее разрешение | 512×288 (16×9 тайлов) | на экран — целым числом физических пикселей на игровой (вокруг — пастельный фон и рамка-«экран»), канвас рендерится ×3 (`RENDER_SCALE`) ради резкого текста |
| Тайл | 32×32 | |
| Девушка / автор | кадр 48×96, фигура ~80 px высотой (2.5 тайла) | крупнее Stardew-пропорции (2 тайла): на 58 px лицо было 4–5 px и персонаж терялся; см. DECISIONS 2026-09-13 |
| Собака (Фрея) | кадр 96×64, фигура ~54 px в высоту (2/3 Настасьи; в профиль шире, чем выше) | |
| Зайчонок | кадр 96×96, фигура ~66 px | увеличен с 32×32 — на 22 px терялся на фоне остальных персонажей; 192×192 оказался перебором |
| Портрет | 64×64 | в панели диалога 1:1 |
| Предмет | 32×32 | лежит «на полу», низ по нижнему краю |
| Панель диалога | 500×148, цельная картинка (не 9-slice: по краям декор), области — `DIALOGUE_PANEL` в `config.ts` | `public/assets/ui/dialogue_box.png` |

Спрайтшит персонажа: строки = направления **down, left, right, up**; столбцы = кадры
**[шаг, стоим, шаг, стоим]**. Ниже — необязательные ещё 4 строки **idle (дыхание)** в том же порядке
направлений, по 4 кадра (нейтраль → вдох → полный вдох → выдох, движение на 1–2 px). Если idle-строк
нет — стоим на кадре «стоим» (колонка 1). Дыхание обычно нужно только виду `down` (персонажи по
умолчанию смотрят в камеру); остальные направления в idle-строках — повторённый кадр «стоим».
Origin спрайта — низ по центру (точка под ногами). `left` можно получить зеркалом `right`
(пайплайн делает сам).

## Перспектива

3/4 сверху (RPG-перспектива): стены зданий видны «в лоб», крыши чуть сверху, земля — плоская
текстура. Персонажи смотрят в 4 стороны. Объекты выше одного тайла (дерево, подъезд с козырьком)
делятся на тайлы: низ — `objects` (коллизия), верх — `overhead` (рисуется над персонажем).
Объекты шире тайла (лавка 2×1) — на соседние тайлы по горизонтали (`bench` + `bench_r`).

**Интерьеры** — как в Stardew Valley: видна только задняя стена (верхний ряд, `wall_inner`, «в лоб»),
боковые и передняя (нижняя, между камерой и полом) стены скрыты — тёмная кромка `wall_dark`
(непроходимая, почти сливается с фоном). Проём в нижней кромке — выход на улицу.

**Изометрии нет.** Карта — прямая сетка, поэтому у любого объекта передняя грань смотрит на зрителя
в лоб, сверху видна узкая полоска (~20–30 % высоты), все горизонтальные рёбра — горизонтальные
линии, боковых граней не видно, никаких поворотов на 30–45°. Ракурс по типам ассетов
(`kind` пайплайна):

| Тип | `kind` | Ракурс |
|---|---|---|
| Земля, пол, крыша | `tile` | строго сверху, бесшовная текстура на весь кадр |
| Стена, окно, дверь | `facade` | плоский фронт, как чертёж |
| Здание целиком | `building` | плоский фронт + узкая полоска крыши |
| Предмет с объёмом (лавка, фонарь, дерево, куст) | `object` | фронт, камера чуть выше; низ = точка опоры |
| Вещь по фото (подарок) | `prop` | то же, что `object`, размер 32×32 |

## Палитра

Общая палитра ~32 цвета, тёплая, слегка приглушённая (Stardew), контурная линия — тёмная
(не чёрная: `#2a1f2d`). Рекомендуется завести `pipeline/palette.png` (уникальные цвета) и
включить `pixel.palette` в `pipeline/config.yaml` — тогда все ассеты квантуются в одну палитру
и гарантированно «дружат». Пока палитры нет — каждый спрайт квантуется до 32 цветов сам по себе.

Заглушки (пока нет арта) используют цвета из `src/data/tiles.json` и `characters.ts`.

## UI

- Панель диалога: светло-розовая рамка с цветами, котиком и зайцем (сгенерирована по референсу
  `refs/ui/dialogue_box_with_avatar.png`), снизу экрана. Слева большая текстовая область, справа
  окошко портрета 64×64 и плашка имени под ним. Текст тёмно-розовый (`DIALOGUE_PANEL.ink`), курсор «▼».
- Внутренний монолог: окошко портрета пустое, имени нет, текст курсивом приглушённым цветом.
- Рамка — цельная картинка: генерировать на светлом однотонном фоне (не хромакей — он ломает
  палитру), фон убирает `gen.py post ui` заливкой от краёв; однотонную часть рамки он растягивает
  по ширине, так что исходник может быть любых пропорций.
- Текст диалога 16 px, имя 14 px (`DIALOGUE` в `config.ts`); Text-объекты рисуются с
  `resolution = RENDER_SCALE`, поэтому шрифт не обязан ложиться на пиксельную сетку.
- Шрифт: пиксельный TTF с кириллицей в `public/assets/fonts/pixel.ttf` (подхватится автоматически).
  Кандидаты: Press Start 2P (широкий, 8px), «PixelOperator»/«Monocraft»/«VT323» — любые с кириллицей.
  Пока файла нет — моноширинный системный.

## Промпт-стиль (для генерации)

Базовая строка — `pipeline/prompts/style.txt`:

> 16-bit era pixel art, cozy indie game style between Stardew Valley and Undertale, 3/4 top-down RPG
> perspective, clean 1px dark outlines, limited palette of about 24 colors, soft cel shading with 2-3
> tones per material, no anti-aliasing, no gradients, no blur, no text, no watermark

Фон генераций — хромакей **magenta `#FF00FF`** (не зелёный: в игре много травы/кустов).
Модели рисуют «псевдо-пиксель-арт» в 1024px — настоящим пиксель-артом его делает
пост-обработка (`docs/ASSET_PIPELINE.md`).

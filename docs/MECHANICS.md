# Механики

Всё описанное реализовано в `src/`. Здесь — как этим пользоваться и какие есть соглашения.

## Сцены

```
Boot ──> Preload ──> World (карта)  +  UI (оверлей, живёт параллельно)
```

- **Boot** — проверяет, какие файлы из `data/assets.ts` реально есть (HEAD-запрос), грузит шрифт.
- **Preload** — грузит существующие файлы, для остальных рисует заглушки (`core/Placeholders.ts`);
  в настоящем `tileset.png` пустые клетки (тайл ещё не нарисован) тоже дорисовываются заглушками
  с цветом и именем из `tiles.json` (`patchTileset`; то же делает редактор карт). Регистрирует
  анимации персонажей, читает сохранение.
- **World** — одна сцена на все локации: `scene.restart({ map, spawn })` при переходе.
- **UI** — панель диалога, подсказка `[E]`, название локации, тосты, инвентарь (иконки посылок в углу,
  панель по `I`), крупная надпись-баннер (финал). Общается с World только через `bus`.
- **MG_\*** — сцены мини-игр (`src/minigames/`), запускаются поверх приостановленного World (см. «Мини-игры»).

Параметры адреса для отладки: `?new` — заново, `?map=<key>&spawn=<name>` — начать с локации,
`?cutscene=<id>` — сыграть катсцену при входе, `?mg=<id>` — сразу запустить мини-игру, `?debug`, `?st`.

## Карты (`src/data/maps/*.ts`)

ASCII-описание, символ → имя тайла через `legend` (общая — `legend.ts`, тайлы — `tiles.json`).

```ts
ground:   ['....', ...]   // земля, обязательно; solid-тайлы (стены) можно класть прямо сюда
objects:  ['  T ', ...]   // объекты поверх земли (пробел = пусто); коллизия по solid из tiles.json
overhead: [...]           // опционально; над персонажем. Кроны деревьев ставятся автоматически по `top` в tiles.json
spawns:   { start: {x, y, dir} }             // точки появления (в тайлах, точка под ногами)
exits:    [{ x, y, w, h, to: 'street', spawn: 'fromYard' }]   // зона в тайлах; наступил — перешёл
npcs:     [{ id, sprite, x, y, dir, dialogue | cutscene, if: ['flag', '!flag'] }]
items:    [{ id, sprite, x, y, dialogue | cutscene, pickup, passable, gift, if }]
triggers: [{ id, x, y, w, h, cutscene, if }] // зона: вошёл — катсцена; снова — только после выхода из зоны
onEnter:  ['intro']                          // катсцены при входе (сами проверяют once/if)
music:    'home'                             // фоновая музыка локации (ключ из data/music.ts)
```

NPC и предметы с `if` появляются и исчезают сразу, как только флаги изменились (после диалога,
катсцены, мини-игры) — уходить с карты не нужно. Забранные предметы (`pickup`) скрываются сами.

Coordinates: тайл (0,0) — левый верхний. Персонаж «стоит» на тайле (y — ноги).
Spawn ставить на 1 тайл внутрь от зоны выхода. Размер карты любой — камера следует за игроком
в пределах карты.

Слои и глубина: ground −20, objects −10, актёры/предметы = их `y` (y-sort), overhead 1e6.

Вода (`~`, тайл `water`) анимируется шейдером (`systems/Water.ts`): поверх каждого прямоугольника
воды на глубине −19 лежит `Shader`-квад, который сам рисует тайл воды из тайлсета с попиксельной
рябью, течением и редкими бликами-штрихами. Только WebGL; на canvas остаётся статичный тайл.

## Движение и коллизии

Свободное движение (arcade physics), скорость `WALK_SPEED`. Тело — маленький прямоугольник у ног
(20×12), поэтому верх спрайта может заходить за объекты. Коллизии: solid-тайлы обоих слоёв, NPC,
непроходимые предметы. Диагональ нормализована.

Анимации актёра: `<sprite>_walk_<dir>` (4 кадра, `WALK_FRAME_RATE`) и `<sprite>_idle_<dir>`. Idle —
дыхание из idle-строк листа (`IDLE_FRAME_RATE`), а если у листа их нет — один кадр «стоим»
(`IDLE_FRAME`); переключается сам при остановке/повороте (`Actor.playIdle`). Направление по умолчанию
у всех актёров — `down` (лицом к камере): спавны и NPC без `dir` смотрят вниз.

## Взаимодействие

Каждый кадр World ищет NPC/предмет в ~1 тайле перед игроком (по направлению взгляда) →
UI показывает `[E] Поговорить/Посмотреть`. По действию:
- NPC: поворачивается к игроку → `dialogue` или `cutscene` → флаг `talked:<id>` → возвращает взгляд.
- Предмет: `dialogue`/`cutscene` → если `pickup`: `has:<id>`, спрайт исчезает → флаг `seen:<id>`.

## Посылки (подарки-коробки) и инвентарь

Каждый подарок — предмет с полем `gift`: на карте стоит коробка (`sprite: 'prop_gift'`). Забрать её можно,
когда стоит флаг `unlock` (у посылок на почте его нет — забираются сразу):

```ts
{ id: 'sewer_gift', sprite: 'prop_gift', x: 19, y: 9,
  gift: { item: 'headphones', unlock: 'minigame:rhythm:won', lockedDialogue: 'sewer_gift_locked' },
  dialogue: 'item_headphones' }   // реплики при открытии; без dialogue — общие из data/gifts.ts
```

Заперта → звук `locked` + `lockedDialogue` (или общая реплика). Иначе коробка прыгает к игроку и
**запакованной** попадает в инвентарь: `GameState.gifts` (`{ id, item, dialogue }` в порядке получения),
флаг `packed:<gift id>`, тост «Посылка забрана (n/N)». Коробка с карты исчезает. Всего посылок в игре —
`totalGifts()` (`data/gifts.ts`, считает предметы с `gift` по всем картам); когда забрана последняя —
флаг `gifts_all`.

**Инвентарь**: в правом верхнем углу — иконки посылок (закрытая коробка — запакована, спрайт предмета —
открыта) и счётчик; `I` — панель со списком (`UIScene`). Отдельного экрана управления предметами нет.

**Открытие — на почте** (катсцена `rabbit_post`, ветка `gifts_all && !gifts_opened`): автор (`me`) выходит
за прилавок, посылки открываются по очереди командой контекста `ctx.openGift(g, [tx, ty])` — коробка
опускается на тайл, крышка (`prop_gift_open`), предмет выпрыгивает, реплики предмета (`dialogue` или
общие), предмет летит к игроку: `has:<item>`, `opened:<gift id>`, тост «Получено: …». После каждой —
комментарий автора (`meGiftLines` в `data/gifts.ts`). В конце — флаг `gifts_opened`, warp на улицу,
где `onEnter` запускает финал `finale` (салют `systems/Fireworks.ts`, баннер `bus 'banner'`, флаг `finale_done`).
В самом конце `finale` — P.S. от автора: `bus 'reveal'` показывает картинку `ui/bouquet_colors.png` с подписью
(цвета букета, который скоро привезёт курьер), ждёт клика/клавиши и эмитит `reveal:closed`, на которую
подписан `call` в катсцене (`UIScene.showReveal`).
`item: 'drawn'` — предмет, нарисованный в мини-игре (спрайт и подпись из `GameState.drawn`; см. «Мини-игры →
draw»); если посылка уже в инвентаре, новый рисунок просто подменяет содержимое.

## Мини-игры (`src/minigames/`)

Запуск — командой катсцены `{ minigame: 'id' }` (или `?mg=<id>`). World ставится на паузу, сцена
мини-игры (`MinigameScene`) рисуется поверх; по `finish({ won, score })` мир продолжается, ставятся
флаги `minigame:<id>:played`, `:won` (навсегда), `:lost` (последний заход), рекорд в `state.scores`.
Дальше катсцена ветвится: `{ branch: { if: ['minigame:rhythm:won'], then: [...], else: [...] } }`.
Реестр — `minigames/index.ts` (id → сцена); общие штуки базовой сцены: баннер, всплывающие подписи,
экран результата (`[Enter]` ещё раз / `[Esc]` уйти), `hudStyle()`.

| id | Где | Что | Победа |
|---|---|---|---|
| `rhythm` | канализация (люк во дворе → `sewer`, триггер перед монстром) | FNF-стиль: стрелки едут снизу вверх по 4 дорожкам, A/S/W/D или стрелки. Чарт строится из мелодии темы (`RhythmScene.buildChart`: дорожка `chartTrack` из `data/music.ts` (для `sewer` — `lead`), ноты ≥ `RHYTHM.minMidi`, дорожка по высоте ноты, ноты чаще `RHYTHM.minGapSec` сливаются), музыка — `data/music.ts` → `sewer` (`nightmare_theme`, 156 BPM). Монстр — тело-спрайт + процедурные щупальца (`Tentacle.ts`: волны + бегущие импульсы на промахах, сжимаются при комбо). **Вторая стадия** с середины чарта (`RHYTHM.stage2.atFrac`): монстр раздувается, и в случайные моменты (`everyMin..everyMax` с) в левой части экрана появляются круги-мишени — кольцо сужается от `radiusFrom` к `radiusTo` за `life` с; клик ЛКМ по кругу оценивается по разнице радиусов (`windowsPx`), не кликнул — промах. Стрелки при этом продолжают идти. | здоровье > 0 в конце (промах −9, попадание +1…+3; окна — `RHYTHM.windows`) |
| `shahed` | улица, триггер-зона на дороге (катсцена `sky_alarm`) | вид на небо, прицел за мышью (или WASD), ЛКМ/пробел — пуск ракеты с крыши: летит по прямой в сторону прицела до края экрана, подрывается в `SHAHED.blast` px от дрона. Боезапас — `SHAHED.ammo` ракет, кончились — раунд завершается. Дроны быстрые, рыскают и иногда делают петлю (`SHAHED.loop`); тёмные — сбивать, зелёные — свои, штраф. | пропущено ≤ `SHAHED.maxMissed` и очки ≥ `SHAHED.targetScore` |
| `feed` | двор, повторный разговор с Фреей (катсцена `freya_talk`; первый разговор — обычный диалог) | «покорми Фрею»: Фрея (её спрайт, idle-анимация) сидит посреди двора, в облачке над ней — что она хочет (миска / мяч / вкусняшка), под облачком — полоска времени. Подать нужное с подноса внизу: 1/2/3, A/S/D или клик по слоту. `FEED.rounds` просьб, время на просьбу линейно от `timeFrom` до `timeTo`; с просьбы `shuffleFrom` предметы на подносе разъезжаются по новым местам (клавиши остаются за слотами). Не то или не успела — ошибка. Очки: `scoreHit` + `scoreFast`, если успела в первой половине времени. | ошибок ≤ `FEED.maxMiss` (после победы играть можно снова — ради очков) |
| `draw` | улица, мольберт (`easel_draw`) | DOM-оверлей в духе Gartic Phone (`DrawOverlay.ts`): холст, палитра, кисть/ластик/заливка, undo, подсказка «что это». Рисунок → `server/draw_server.py` → Nano Banana → спрайт 32×32 + название и подпись → вебхук. Без бэкенда спрайт делается из самого рисунка. | всегда, если не отменена (Esc) |
| `bank` | почта, компьютер на прилавке (`post_computer`) — пасхалка, не игра | DOM-оверлей «монитор + окно браузера» (`BankOverlay.ts`): банковское приложение, «200 000 ₴ доступно», «Отправить Настасье», поле номера карты (16 цифр, группируется по 4) и сумма. Ввёл → полоса «VISA, платёж обрабатывается» → уведомление «у бедняка нет столько денег». Ничего никуда не отправляется. | дошли до уведомления (Esc раньше — lost) |

Константы (окна попадания, количество дронов, скорость стрелок, время на просьбу) — `RHYTHM`, `SHAHED` и `FEED` в `config.ts`.

## Звук (`core/Audio.ts`)

`audio.playMusic('home')` / `audio.stopMusic()` / `audio.sfx('bark')`; `M` — mute; **Esc — настройки** (UIScene: ползунки
музыки и эффектов, ↑↓/←→ или клик по полосе, по умолчанию `AUDIO.music/sfx` = 20 %; пока панель открыта — ввод мира
заблокирован через `lockInput`); громкости в localStorage (`AUDIO.key`).
Голос в диалоге: `CharacterDef.voice` (`characters.ts`) — при печати реплики `audio.voice()` играет случайный из
загруженных `assets/voice/<clips>_<n>.ogg` (короткие «а/э», новый не начинается, пока звучит предыдущий), файлов
нет — блип с `voice.rate` (Настасья выше, автор ниже); персонажи без `voice` — обычный блип.
Музыка: ключи в `data/music.ts` — если есть `public/assets/music/<файл>.ogg`, играет он, иначе тема
синтезируется из `music/<тема>.json` (`core/Synth.ts`: осцилляторы по трекам pad/piano/guitar/bass/bells/arp
и organ/harp/lead/brass/choir/drums для `nightmare_theme`). Ключи: `home` → `home_theme_2`, `dusk`/`sky` →
`dusk_theme2` (один файл `dusk.ogg`), `sewer` → `nightmare_theme`; у «покорми Фрею» своего ключа нет —
тема двора продолжает играть (`MinigameScene.keepMusic`). Файл длиннее темы (такт хвоста реверба из FL) —
зацикливается по `theme.meta.bars` (маркер `loop`).
Эффекты: файл `assets/sfx/<name>.ogg` (расширение можно переопределить в `SFX_EXT` в `data/assets.ts`,
если файл не .ogg), иначе синтез (`playSynthSfx`, список — `SFX_NAMES` в `data/assets.ts`).
Реплика диалога может иметь `sfx`; печать текста «блипает». Ритм-игра берёт `audio.beat()` — текущую
долю музыки (отрицательная во время отсчёта `leadBeats`), поэтому файл и синтез взаимозаменяемы, если
темп файла равен `theme.meta.bpm` (или `bpm` в `data/music.ts`, если он задан — но `bpm`/`transpose`
меняют только синтез, файл они не ускоряют).
Фоновый эффект локации: `MapDef.ambientSfx` (имя из `SFX_NAMES`) — `WorldScene.startAmbient()` проигрывает
его со случайными паузами (1.8–4.8 с) и случайным rate, пока сцена локации жива; таймер снимается на
`SHUTDOWN` сцены (переход на другую карту, катсцена-`warp`). Пример — капель в канализации: `sewer.ambientSfx = 'drip'`
(файл `assets/sfx/drip.mp3`, единственный эффект с расширением, отличным от `.ogg`).

## Диалоги (`src/data/dialogues/index.ts`)

```ts
{ who: 'freya', text: 'Гав!' }                       // портрет freya_portrait, имя из characters.ts
{ who: 'anastasiia', text: '...', portrait: 'anastasiia_portrait_happy' } // другая эмоция (файл portraits/anastasiia_happy.png)
{ think: true, text: 'Внутренний монолог' }         // без портрета/имени, курсив
{ who: 'rabbit', text: 'Расписаться?', choices: [{ label: 'Да', next: 'rabbit_yes', setFlag: 'signed' }, { label: 'Нет' }] }
```

Диалог = массив реплик **или** функция `(state) => реплики` для вариативности по флагам.
Текст печатается посимвольно (`DIALOGUE.charsPerSec`); действие — досказать / дальше; клик тоже работает.
Программно: `dialogue.run('id')`, `dialogue.lines([...])` — возвращают Promise.

## Катсцены (`src/data/cutscenes/index.ts`) — как event-скрипты Stardew

Катсцена = `{ id, once?, if?, script: CutsceneCmd[] }`. Команды выполняются по очереди,
`parallel` — одновременно. На время сцены управление отключено (счётчик `InputLock`), подсказки
скрыты. `once` ставит флаг `cutscene:<id>`. Актёр `player` — игрок; остальные — id NPC на карте
или созданные `spawn`. NPC, которых катсцена двигала (`move`/`moveTo`/`path`) или поворачивала
(`face`), по её окончании (кроме `warp`) автоматически поворачиваются обратно лицом к камере
(`down`) — отдельная команда для этого не нужна.

| Команда | Что делает |
|---|---|
| `{ fade: 'in'/'out', ms }` | затемнение камеры |
| `{ wait: ms }` | пауза |
| `{ actor, move: [dx, dy], speed }` | пройти dx тайлов по X, затем dy по Y |
| `{ actor, moveTo: [tx, ty] }` / `{ actor, path: [[tx,ty], ...] }` | идти в точку / по точкам (по прямой, сквозь коллизии) |
| `{ actor, face: 'left' }` | повернуться |
| `{ actor, anim: 'key' }` / `{ actor, anim: '', stop: true }` | проиграть анимацию по ключу / вернуться к idle |
| `{ actor, emote: '!', ms }` | значок над головой (`!`, `?`, `♥`, `...`) |
| `{ actor, teleport: [tx, ty] }` | мгновенно переставить |
| `{ say: 'freya', text }` / `{ think: text }` / `{ dialogue: 'id' }` | реплика / монолог / целый диалог |
| `{ camera: { pan: [tx, ty], ms } }` | камера едет к тайлу (перестаёт следить за игроком) |
| `{ camera: { follow: 'player' } }` | камера возвращается к актёру |
| `{ camera: { shake: 0.01, ms } }` | тряска |
| `{ spawn: { id, sprite, at: [tx, ty], dir } }` / `{ remove: id }` | создать/убрать актёра |
| `{ setFlag: 'name', value }` / `{ give: 'item' }` | флаг / предмет в инвентарь |
| `{ warp: { map, spawn } }` | перейти на карту — **только последней командой** |
| `{ minigame: 'rhythm' }` | мини-игра поверх мира; после неё флаги `minigame:<id>:won/lost` |
| `{ branch: { if: ['flag', '!flag'], then: [...], else: [...] } }` | ветвление по флагам |
| `{ music: 'dusk', ms }` / `{ music: null }` / `{ sfx: 'roar' }` | музыка / тишина / звук |
| `{ parallel: [...] }` | выполнить одновременно |
| `{ call: async (ctx) => {...} }` | произвольный код (ctx: world, getActor, spawnActor, state, dialogue, warp, runMinigame, openGift) |

Запуск: `onEnter` карты, `cutscene` у NPC/предмета, `triggers` карты, или `scene.runner.runById('id')`.
Рукописные катсцены — `cutscenes/index.ts`, сохранённые редактором — `cutscenes/edited.ts`
(перекрывают одноимённые). То же с диалогами (`dialogues/edited.ts`).

Пример (вступление):
```ts
script: [
  { fade: 'in', ms: 800 },
  { think: 'Сегодня какой-то особенный день.' },
  { actor: 'player', move: [0, 1] },
  { parallel: [{ actor: 'freya', path: [[7, 5], [6, 6]], speed: 110 }, { actor: 'player', face: 'right' }] },
  { actor: 'freya', emote: '!' },
  { say: 'freya', text: 'Гав!' },
]
```

## Состояние (`core/GameState.ts`)

`flags` (Record<string, boolean>), `inventory` (предметы), `gifts` (запакованные посылки), `map`, `spawn`;
автосохранение в localStorage (`bgame.save.v1`). Условия `if: ['a', '!b']` — все должны выполняться.
Соглашения по именам: `cutscene:<id>`, `talked:<npc>`, `has:<item>`, `seen:<item>`, `packed:<gift>`,
`opened:<gift>`, `gifts_all` / `gifts_opened` / `finale_done`, `minigame:<id>:won|lost|played`, произвольные
`intro_done` и т.п. Кроме флагов сохраняются `scores` (рекорды) и `drawn` (нарисованный подарок: название,
подпись, URL спрайта). `?new` в URL — сброс.

## Ввод

WASD/стрелки — движение; E / Space / Enter / Z — действие и листание диалога; клик/тап — листание.
В диалоге ↑/↓ — выбор варианта. I — инвентарь. Esc — настройки звука (и закрыть инвентарь). M — звук вкл/выкл. В мини-играх — свои клавиши (см. выше), Esc — выйти.

## Редактор карт, катсцен и диалогов (`editor.html`)

`npm run dev` → http://localhost:5173/editor.html. Данные берутся из тех же модулей, что и игра;
сохранение — dev-плагин Vite (`vite.config.ts` → `POST /__editor/save`) пишет прямо в `src/data/*.ts`:
карта → `maps/<key>.ts` (+ `maps/index.ts` для новой), катсцена → `cutscenes/edited.ts`,
диалог → `dialogues/edited.ts`. Формат файлов тот же, что у рукописных (см. `src/editor/serialize.ts`),
так что их можно править и руками; комментарии в файле карты при сохранении теряются.

- **Карты**: три слоя, палитра из `tiles.json` (символ подбирается по легенде; тайлу без символа
  редактор заведёт свой в `legend` карты), кисть/ластик/заливка/пипетка (ПКМ — пипетка), объекты
  (появления, выходы, NPC, предметы с подарками, триггеры) — кнопки «＋», перенос мышью, форма
  свойств справа, размер карты, «▶ В игре» — превью внизу страницы на этой карте.
- **Катсцены**: список команд-карточек по схеме `src/editor/schema.ts` (все команды `CutsceneCmd`,
  вложенные `parallel`/`branch`), порядок, копирование, «▶ Проиграть» — игра с `?cutscene=<id>`.
  Катсцены с `call` (код) только просматриваются.
- **Диалоги**: реплики (кто/мысль, текст, портрет, звук, варианты ответа). Диалоги-функции — в коде.
- Ctrl+S — сохранить. После сохранения страница перечитывает данные (Vite HMR).

## Заглушки

Пока нет PNG — `Placeholders.ts` рисует цветные прямоугольники с буквами (персонажи с «глазами»
по направлению и подобием шага). Это позволяет собирать и тестировать всю игру до арта.
Файл появился в `public/assets/...` → подхватится сам (Boot проверяет наличие).
